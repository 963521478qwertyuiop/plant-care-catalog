# Каталог домашних растений (Plant Care Catalog)

## Описание проекта
**Plant Care Catalog** — это веб-приложение для ведения каталога комнатных растений и отслеживания истории ухода за ними. 

### Проблема
Владельцы домашних растений часто забывают, когда последний раз поливали цветок, какое освещение ему нужно и когда его пересаживали. Ведение записей в блокноте неудобно, а запоминать всё в голове — ненадёжно.

### Решение
Приложение позволяет создать личный каталог растений, указать индивидуальные параметры (частота полива, тип освещения) и фиксировать каждое действие (полив, удобрение, пересадка) в журнале. Это помогает систематизировать уход и сохранять здоровье растений.

## Основные сущности
1. **Plant (Растение)** — карточка растения.
   - `id`: уникальный идентификатор.
   - `name`: название растения (например, «Фикус»).
   - `wateringIntervalDays`: рекомендуемая частота полива в днях.
   - `lightLevel`: требуемое освещение (LOW, MEDIUM, HIGH).
   - `ownerUsername`: имя владельца (для разграничения доступа в будущем).

2. **CareLog (Запись об уходе)** — событие, связанное с растением.
   - `id`: уникальный идентификатор.
   - `plant_id`: ссылка на растение (связь One-to-Many).
   - `actionType`: тип действия (WATERING, FERTILIZING, REPOTTING).
   - `date`: дата выполнения действия.
   - `note`: произвольный комментарий (например, «добавил 2 таблетки удобрения»).

## Функциональные требования (MVP)
В минимальную жизнеспособную версию (MVP) входят следующие возможности (отмечены тегом `mvp` в Issues):
- CRUD-операции для растений (создание, чтение, обновление, удаление).
- CRUD-операции для записей об уходе.
- Просмотр списка всех растений в виде таблицы.
- Просмотр истории ухода для конкретного растения.
- Базовая валидация вводимых данных (например, частота полива не может быть отрицательной).

## Архитектура и стек технологий
- **Язык программирования:** Java 17+ (в проекте используется Java 25).
- **Фреймворк:** Spring Boot 3.5.6.
- **Работа с БД:** Spring Data JPA, Hibernate.
- **База данных:** PostgreSQL 15.
- **Шаблонизатор:** Thymeleaf (для серверного рендеринга HTML-страниц).
- **Сборка:** Apache Maven.
- **Контейнеризация:** Docker, Docker Compose.
